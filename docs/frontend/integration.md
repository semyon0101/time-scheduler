# Интеграция Frontend с Backend API

## 1. Конфигурация соединения

Frontend подключается к Backend API через клиент `frontend/src/api.ts`.

- **Базовый URL:** Задается через переменную окружения `VITE_API_URL` (по умолчанию `/api` в dev-proxy или `http://localhost:8000/api`).
- **Идентификация сессии:** Каждый запрос отправляет заголовок `X-Dispatcher-Id` (генерируется и сохраняется в `localStorage` и `cookies`).

---

## 2. Основные API эндпоинты

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/session/init` | Инициализация рабочего пространства диспетчера |
| `GET` | `/api/state` | Получение полного снимка состояния (инженеры, задачи, маршруты, метрики) |
| `POST` | `/api/demo/seed` | Загрузка датасета (`vostok`, `yugcenter`, `yugovostok`) |
| `POST` | `/api/engineers` | Добавление нового выездного инженера |
| `DELETE` | `/api/engineers/{id}` | Удаление инженера |
| `POST` | `/api/engineers/{id}/toggle_status` | Снятие инженера со смены (необратимый перевод в оффлайн) |
| `GET` | `/api/engineers/{id}/explanation` | Получение XAI-обоснования назначения/резерва инженера |
| `POST` | `/api/tasks` | Создание новой заявки |
| `DELETE` | `/api/tasks/{id}` | Полное удаление заявки |
| `POST` | `/api/tasks/{id}/cancel` | Отмена заявки |
| `GET` | `/api/tasks/{id}/explanation` | Получение XAI-обоснования по заявке |
| `POST` | `/api/schedule/optimize` | Запуск оптимизации расписания (VRPTW) |
| `POST` | `/api/schedule/replan` | Перепланирование в реальном времени при событиях |
| `POST` | `/api/session/reset` | Сброс данных текущей сессии |

---

## 3. Формат ответа StateResponse

Каждая мутация состояния возвращает полный актуальный объект `StateResponse`:
- `dispatcher_id`: ID сессии
- `active_preset`: Текущий загруженный пресет данных
- `engineers`: Список инженеров и их статусы
- `tasks`: Список заявок
- `schedule`: Помаршрутное расписание (остановки, расстояния, временные окна)
- `metrics`: Метрики оптимизации (пробег, задействованные инженеры, процент сокращения)
- `unassigned_tasks`: Нераспределенные заявки с указанием причины
