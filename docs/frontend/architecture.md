# Архитектура Frontend (React + TypeScript + Vite + Tailwind + Leaflet)

## 🎨 1. Обзор клиентской архитектуры

Фронтенд представляет собой быстрый SPA (Single Page Application) на базе React 18, TypeScript и Vite, спроектированный для диспетчеров выездных бригад.

---

## 🗺️ 2. Картографический движок (Leaflet SVG Engine)

В [`frontend/src/components/MapView.tsx`](file:///work/time-scheduler/frontend/src/components/MapView.tsx) используется картографический движок **Leaflet**:
* **Надежность 100%:** Полилинии маршрутов отрисовываются как нативные векторные **SVG `<path>`** элементы непосредственно в DOM. Это полностью исключает потерю контекста WebGL и артефакты отсутствия линий при отсутствии дискретного GPU.
* **Светлая растровая подложка CARTO Voyager:** Быстрые растровые тайлы с цветным контрастным оформлением дорог и кварталов.
* **Двойная обводка:** Каждая линия маршрута имеет белую подложку (casing) и цветной основной контур бригады.
* **Фокусировка на отрезке доезда:** Клик на время перегона в таймлайне рисует янтарный штриховой SVG-маршрут с плавающей плашкой километража и кнопкой сброса `[✕]`.

## ⏱️ 3. Вертикальный таймлайн (`VerticalTimeline.tsx`)

Расписание инженеров реализовано как единый переиспользуемый компонент со строгим интервалом **08:00 – 22:00**:
1. **Detailed Mode (в карточке инженера):** Хронологическая вертикальная ось дня:
   * Выезд со стартовой точки в начале смены.
   * Отрезки доезда с расчетом времени и километража (кликабельны для подсветки на карте).
   * Остановки с порядковым номером `#`, временем прибытия, окном клиента и кнопкой генерации ИИ-обоснования.
   * Окончание смены.
2. **Compact Mode (в общем списке инженеров):** По умолчанию **не развернута** (collapsed). Раскрывается по клику для мгновенного предпросмотра дня бригады.

## 🏷️ 4. Двухуровневый поиск и единая система тегов (`tags.ts`)

В [`frontend/src/utils/tags.ts`](file:///work/time-scheduler/frontend/src/utils/tags.ts) разделены понятия модификаторов и тегов:
* **Модификаторы поиска (одиночный выбор):**
  * Для инженеров: `Все`, `На линии`, `Резерв`, `Сход` (строго без скобок), `Изменения`.
  * Для заявок: `Все`, `В графике`, `Не распределенные`, `Отмененные`, `Изменения`.
* **Теги фильтрации (множественный выбор):**
  * 3 канонические квалификации: `Локальные работы`, `Работы на подключение и дозаказы`, `Аварийные работы`.
  * 2 уровня важности: `Срочная`, `Обычная`.
  * Бейдж проблемы: `Проблемная`.
* **Поисковая строка:** ищет как по тексту названия/адреса/#ID, так и по совпадению с любым из тегов объекта.
